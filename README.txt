MAHIRA MEN — FULL-STACK E-COMMERCE

WHAT IS INCLUDED
- Real Node.js + Express backend
- SQLite database (mahira.db is created automatically)
- Customer signup/login/logout
- Password hashing with bcryptjs
- Session-based authentication
- Product catalogue and search/category filtering
- Product detail pages
- Database-backed cart and wishlist
- Checkout and order creation
- Customer order history
- Admin dashboard
- Admin product create/edit/delete
- Admin order status updates
- Stock deduction after order
- Responsive fashion UI
- CSS 3D card effects, parallax-style hero, hover animations
- Mobile layout

REQUIREMENTS
1. Install Node.js LTS from https://nodejs.org/
2. VS Code is recommended.

RUN
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open Terminal -> New Terminal.
4. Run:
   npm install
5. Then run:
   npm start
6. Open:
   http://localhost:3000

IMPORTANT
This is a local/demo ecommerce system. Before production use:
- change SESSION_SECRET
- change/remove the seeded admin password
- use a production session store
- add CSRF/rate limiting/validation
- connect a real payment provider
- use licensed product images
- deploy behind HTTPS
